Privacy policy

This policy describes how the Better Route Plus app on iPhone and iPad handles information.

Effective November 6, 2026. Publisher: Valley Software.

Better Route Plus is a business tool for invoicing, credits, and payments. It syncs with a SlowBooks server that you configure. The app does not send that information to a Valley Software server.

On-device database

The app stores these records in a database on the device:

  • Customers
  • Items
  • Accounts
  • Invoices
  • Credits
  • Payments
  • Notes
  • The pending sync queue
  • The server address
  • Preferences
  • A local invoice counter

The API token is not stored in this database.

If the database cannot be used

If the on-device database cannot be used, the app warns you and uses session memory.

API token

The API token is stored in the iOS Keychain. That Keychain item is not synchronizable and is not shared. It is available after the first unlock of the device. It is not marked this-device-only, so a normal device backup may include it.

Camera

The camera is used to read barcode and QR code text. The app does not store photos or videos from the camera.

Network and your server

The app contacts only the SlowBooks server you choose. It does not contact a Valley Software server. There is no preconfigured server address or API token.

HTTPS is the default. The app uses HTTP only if you explicitly opt in for a trusted network.

Authenticated calls send the API token as a bearer token. A reachability check may omit the token. The network session does not keep cookies on disk.

On the server you choose, the app reads and writes:

  • Settings
  • Customers
  • Items
  • Accounts
  • Invoices
  • Credit memos
  • Payments

The operator of that server receives the information you sync and governs the server, including how the operator keeps and uses that information.

Printing

Printing uses a paired external accessory, AirPrint, or a PDF shared to a destination you select. Printed output and shared PDFs go to that destination. They are not sent to Valley Software.

The app saves the last accessory serial number, connection identifier, printer width, and printer language.

Exports

The app can make temporary spreadsheets of print history or pending payments and pass them to the system share sheet. You select the destination. A spreadsheet may contain names, dates, totals, invoice numbers, payment method, check number, and amounts.

What the app does not include

Better Route Plus does not include:

  • An analytics service
  • A crash-reporting service
  • Advertising
  • Tracking
  • iCloud
  • CloudKit
  • A shared Keychain
  • A card reader
  • A preconfigured server address or API token
  • A cloud backup operated by Valley Software

Device backup

Valley Software does not operate a cloud backup for the app. The on-device database is not excluded from a normal device backup. Those backups are controlled by Apple and by the backup settings on the device. A normal device backup may also include the API token stored in the Keychain.

Children

Better Route Plus is a business tool. It is not intended for children, and it does not offer a child profile.

Changes

When this policy changes, Valley Software will update the effective date on this page.

Contact

Questions about this policy, or requests about information the publisher can address, can be sent to Valley Software at CIO@hektikoptics.com.

Information synced to the SlowBooks server you chose is received by that server’s operator. Questions about how that server stores or deletes synced information go to the operator who governs it.
