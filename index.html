Support

Better Route Plus is an iPhone and iPad app for invoicing, credits, and payments. It syncs with a SlowBooks server that you configure.

Published by Valley Software. Privacy policy effective November 6, 2026.

Contact

Email Valley Software at CIO@hektikoptics.com for support or privacy questions.

Describe what you were trying to do and what the app did. If the question is about a connection, say whether you expected HTTPS or an HTTP connection on a trusted network. Do not include your API token. Include customer, invoice, or payment details only when they are needed to explain the problem.

The server you choose

The app contacts only the SlowBooks server whose address you enter. It does not come with a server address or an API token, and it does not contact a Valley Software server.

HTTPS is the default. HTTP is used only when you explicitly opt in for a trusted network. Authenticated requests send your API token as a bearer token. A reachability check may omit the token.

The app can read and write settings, customers, items, accounts, invoices, credit memos, and payments on that server. The operator of the server you choose receives the synced information and governs that server.

Information on this device

An on-device database stores customers, items, accounts, invoices, credits, payments, notes, the pending sync queue, the server address, preferences, and a local invoice counter.

The API token is stored in the iOS Keychain, not in that database. The Keychain item is not synchronizable and is not shared. It becomes available after the first unlock. It is not limited to this device only, so a normal device backup may include it.

If the database cannot be used, the app warns you and uses session memory.

Camera

The camera reads barcode and QR code text. The app does not store photos or videos from the camera.

Printing and shared files

You can print with a paired external accessory, with AirPrint, or by sharing a PDF to a destination you select. That output goes to the destination you choose. It is not sent to Valley Software.

The app saves the last accessory serial number, connection identifier, printer width, and printer language.

You can export a temporary spreadsheet of print history or pending payments through the system share sheet. You choose the destination. The file may contain names, dates, totals, invoice numbers, payment method, check number, and amounts.

Privacy policy

The Better Route Plus privacy policy describes the same behavior in full, including device backup, what the app does not include, and the November 6, 2026 effective date.
